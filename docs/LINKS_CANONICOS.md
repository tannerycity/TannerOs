# Links canónicos de TannerOS

## Links públicos oficiales

Estos son los links que Administración, WhatsApp Business y comunicación deben compartir normalmente:

- Registro Tanner: `https://app.tannerycity.com/registro/`
- Pedidos: `https://app.tannerycity.com/pedido/`
- Programas y eventos: `https://app.tannerycity.com/programas/`

El Registro Tanner es el embudo principal y permite clasificar el interés como jugador, portero o academia/otra actividad. Todos entran a Prospectos para seguimiento.

## Scouting

- Registro de talento / scouting externo: `https://app.tannerycity.com/registro/scouting/`
- Módulo interno de Scouting: `https://app.tannerycity.com/scouting/`

## TannerOS interno

- Acceso principal de trabajo: `https://app.tannerycity.com/`

Desde el acceso principal se navega a jugadores, finanzas, asistencia, prospectos, scouting, academias, pedidos y demás módulos habilitados por rol.

## Aliases de campaña

No son links operativos que Administración necesite memorizar. Se mantienen para campañas, anuncios, QR y atribución:

- `https://app.tannerycity.com/registro/jugadores/`
- `https://app.tannerycity.com/registro/porteros/`

Ambos usan el mismo embudo y precargan el tipo/campaña correspondiente.

## Compatibilidad legacy

Los links viejos permanecen como redirects y no deben usarse para piezas nuevas:

- `/?registro=1` -> `/registro/`
- `/?pedido=1` -> `/pedido/`
- `/?inscripcion=1` -> `/programas/`
- `/?cursoverano=1` -> `/programas/`
- `/v2` -> `/`

Regla: toda pieza nueva usa únicamente links canónicos. Los aliases y links legacy existen solo para compatibilidad y medición.
