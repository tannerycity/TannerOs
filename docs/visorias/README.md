# Paquete para Claude Code — Consentimientos de visorías de Tannery City FC

## Cómo usarlo

1. Descomprimir los archivos dentro de una carpeta `docs/visorias/` del repositorio que Claude Code pueda leer (o adjuntarlos a la sesión).
2. Entregar a Claude Code **`00_PROMPT_CLAUDE_CODE.md` como instrucción central**, indicándole que lea además los otros tres archivos.
3. Solicitar diagnóstico del repositorio, implementación en rama de trabajo, migraciones no destructivas y resultados de tests.
4. Completar todos los `[CAMPOS]` con datos reales. No publicar un consentimiento con información ficticia.
5. Solicitar revisión de un abogado de Guanajuato, validación de seguros y aprobación de seguridad física antes de activar formularios en producción.

## Documentos

- `00_PROMPT_CLAUDE_CODE.md`: requerimientos para implementar en software.
- `01_CONSENTIMIENTO_VISORIAS_MACHOTE.md`: consentimiento informado completo.
- `02_AVISO_PRIVACIDAD_VISORIAS_MACHOTE.md`: aviso integral de privacidad.
- `03_OPERACION_Y_QA_VISORIAS.md`: checklist operativo y pruebas de seguridad.
